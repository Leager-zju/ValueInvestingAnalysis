# 一页速查

> 规则很多，但你日常只需要记住这一页。细节再翻对应 reference。

## 0. 先问一句：要不要跟踪

分析一只**新标的**时，第一个动作不是取数，是问：

> **加入每日任务分析，还是只做一次性分析？**

| 回答 | 走哪 | 留下什么 |
|---|---|---|
| 加入 | 工作流 A 完整建档 | 写 `portfolio.json`、三槽位报告、每日早盘/尾盘任务、历史日志 |
| 不加入 | 工作流 D 临时分析 | **一份报告**落 `reports/_adhoc/`，主档案零写入 |

- 用户说「帮我建档 / 我要跟这只」→ 视为已回答"加入"，不必再问
- 已建档的标的再分析 → 不问，直接进当日任务
- 临时分析**照样要把期权、四锚、硬约束全算完**——少算不会让结论更安全，只会让它没依据
- 临时报告必须带日期与"临时"字样、放 `_adhoc/` 子目录，**不许用 `<代码>-deep.html` 命名**
- 临时分析跑在 `VI_DATA_DIR` 隔离目录里，**画像要照抄主库**：缺省为 `mid`，会关掉 C 通道，买点就跟正式建档不一样了

## 1. 判断顺序（永远这个顺序）

```
① 股价由哪些因子驱动？（drivers）
② 它是哪一类公司？（形态 → 只用来起手找因子）
③ 现在价格在哪个区间？（五档）
④ 我的仓位状态？（空仓 / 底仓 / 波段）
⑤ 该走哪个通道？（A/B/C）
```

**因子在前，分类在后。** 分类错了但因子挖全了，结论通常仍对；反过来一定错。

## 1.5 无状态原则（比任何一条规则都优先）

**每次分析只看"此刻的状态"：价格、持仓、估值锚、因子读数、画像参数。**
不看上次什么时候交易、上次结论对不对、浮亏多少天。

分批节奏用**价格**表达，不用**时间**表达：价格每再下移 5% 才加一轮；价格不动就不加。

## 2. 日常只用 5 条命令

| 想干什么 | 命令 |
|---|---|
| 建档 / 更新持仓（照抄券商） | `upsert --code C --shares N --cost P [--budget B]` |
| 今天该怎么看 | `calc --code C --price P` |
| 这笔单能不能下 | `check-order --code C --side buy\|sell --shares N --limit P --prev-close X ...` |
| 出报告 | 标记期权兑现/证伪 | `option` 传一条 `{name, status: hit\|missed}` |
| `new-report --code C --session deep\|morning\|afternoon` |
| 总入口 | `index` → `reports/index.html` |
| 记当日判断 | `log --session ... --action-type buy\|sell\|hold [--target-price P]`（同日同任务覆盖） |

**`calc` 的所有告警都在 `warnings` 数组里**——读这一个字段就够，不用逐个猜 `type_warning` / `driver_warning` / `option_warning`。

其余命令只在特定场景用（`option` 登记期权、`set-drivers` 登记因子、`plan-swing` 算波段仓、`index` 刷新索引）。

## 3. 四个参数，两个属于人、两个属于票

| 参数 | 属于 | 取值 | 影响什么 |
|---|---|---|---|
| `regret_aversion` | **人** | low / mid / high | 空仓时愿意等多深的价格 |
| `drawdown_tolerance` | **人** | 0.15 / 0.25 / 0.35 | 浮亏超过它时弹出情绪防护提示 |
| `entry_style` | **票** | left / swing / right / mixed | 钱怎么进场 |
| `entry_zone_ratio` | **票** | 0 – 1（默认随风格） | 合理区内哪一段允许建仓 |

优先级：**标的 > 全局 > 风格默认**。

## 4. 六类形态（林奇的骨架，门槛已本地化）

| 形态 | 一句话 | 估值范式 |
|---|---|---|
| 缓慢增长型 | 行业见顶，增长靠提价与份额 | PE 分位 / 股息率锚 |
| 稳健增长型 | 龙头，5–20% 稳定增长，ROE ≥12% | PE 历史分位 |
| 快速增长型 | ≥20% 且可持续（不是并表/低价换量） | PEG |
| 周期型 | 有亏损年或净利峰谷比 >3 倍 | **CAPE + PB**（当期 PE 是陷阱） |
| 困境反转型 | 近 2 年亏损、正在修复 | 正常化盈利 |
| 隐蔽资产型 | 市值 < RNAV×0.8 **且有催化剂** | RNAV / 分部估值 |

- **红利只是标签**，不是形态。
- 判定必须附**一条反方证据**；改判必须给**结构性理由**。

## 5. 五档区间 → 动作

| 价格位置 | 未投入 | 已投 ≤1/3 | 已投 ≥2/3 |
|---|---|---|---|
| 深度低估（≤ deep） | 建仓至 1/2–2/3 | 加到 2/3 | 可加，先查 A 类信号 |
| 低估（deep–core） | 建底仓 1/3 | 加至 2/3 | 持有 |
| 合理区（core–fair_high） | 窗口内按 C 通道建底仓 | 补至 1/3 | 持有不加 |
| 偏贵（fair_high–透支） | 不买 | 持有 | 持有 |
| 透支（> 透支线） | 不买 | 减 1/3 | 减至 1/2 预算 |

**透支线已含期权全额**——用它卖掉一家正在变好的公司，是另一种踏空。

## 6. 三个通道

| 通道 | 触发价 | 单笔上限 | 前提 |
|---|---|---|---|
| A 低估区建底仓 | ≤ 底仓线 | 可用全额 | 质地 ≥6、无 A 类信号 |
| B 深度低估加仓 | < 深度低估线 | 可用全额 | 同上，锚未下修 |
| C 时间换价格 | ≤ 核心+ratio×(上沿−核心) | **1/2** 可用 | 踏空厌恶 high、质地 ≥8、已登记期权 |

单笔不按 1/3、1/4 切分：A/B 用可用全额，C 用 1/2（与其累计上限对齐，不是通道比例）。`check-order` 对 >50% 可用的大单只给 `concentration_note` 提示，不拦截。

C 通道不是追高许可，是给"价格长期不回落"准备的合法路径。

## 7. 三条铁律

1. **不因跌了卖**：减仓只有两个理由——基本面恶化（A1–A7）、估值透支。
2. **不猜底不猜顶**：不追求"买在最低点上方 1%"，用分档挂单 + 时间摊薄。追求精确低点 = 必然踏空。
3. **波段 ≠ 摊薄，判据不是方向，是「有没有写下来的卖出价」**：有（且 ≥ 买价×1.05）→ 波段；没有 → 摊薄加仓。下跌途中只有买、没有卖也没有卖价，就是摊薄。
   - **先高后低**（先卖后买，`--buyback-price` / `--swing-buyback`）：买回价两条线 = **≤ 卖出价×0.95**、**≤ fair_high**（**不看建仓窗口**——窗口管"要不要新增持仓"，不管"要不要把刚卖的买回来"）；买回股数与金额都 ≤ 上轮卖出。
   - **先低后高**（先买后卖，`--swing-open --target-sell-price` → 兑现 `--swing-exit --swing-entry-price`）：**豁免建仓通道与矩阵 `room_amount`**（底仓建满后再等低估价，等到的是第二份底仓）；改校验「卖价≥买价×1.05、卖端≤fair_high、**买价≤fair_high÷1.05（价格闸门）**、金额≤可用」。规模无比例上限——波段仓 = 总持仓 − 底仓，自动派生。
   - **额度看对地方**：底仓还能加多少 → `calc.matrix.room_amount`；波段能用多少钱 → `calc.swing.buy_power`。**两者经常一个为 0、一个是全部可用资金，拿错就得出完全相反的结论。**

## 7.5 政策事件一句话

**政策只能压买价，不能抬卖价。** 用它下调 `core_entry`（要更高安全边际），不动 `fair_high`。
必须带传导链（政策→变量→财务科目）、窗口与验证点；写不出就是情绪，不许登记。

## 7.6 利率（10Y 美债）一句话

**利率只改倍数，不改盈利；可双向，但必须有基准。**

```
base_* × k，k = 1 + β_rate × (y_now − rate_baseline)，限幅 0.85 ≤ k ≤ 1.15
β：成长 −15% / 稳健 −9% / 红利公用 −6% / 困境反转 −5% / 周期 −2% / 金融 0（禁用线性修正）
```

- **没有 `rate_baseline` 就不许改锚**；改完立刻把基准更新为新值。
- 相对基准变动 **<25bp 不动锚**，但报告里要写一句"未触发"，别改了不说、也别不说没改。
- **利率不是买卖理由**：减仓仍然只有"基本面恶化 / 估值透支"两条。

## 8. 期权定价只记一句话

```
每股期权价值 = Σ（兑现在每股上值多少钱 × 概率 × 折价）
payoff = Δ每股盈利 × 合理倍数   ← 最容易漏乘倍数
```

合计超过基础价值 30% 的部分只按 50% 计入。**没有时间表的传闻不进估值。**

**期权会过期**：超过 `window` 未兑现 → 逾期 ≤180 天概率 ×0.5，>180 天 ×0（视为证伪）。兑现了就标 `hit` 并把它从期权里剔到基础价值里，不要重复计价。

## 9. 常见错误清单

| 错误 | 一句话纠正 |
|---|---|
| 只算下行保护 | 优质公司会被算便宜，买点永远不成交 |
| 用当期 PE 判周期股 | 盈利高点 PE 最低，正好买在顶部 |
| 单点挂深度折价 | 价格不回来，仓位永远是 0 |
| 用成交价自己算成本 | 各券商佣金不同，照抄券商的 |
| 把分类当结论 | 分类只是找因子的向导 |
| 在浮亏扩大时重做画像 | 那时的答案代表情绪，不代表偏好 |

## 10. 每次分析输出必须有的东西

1. 驱动因子（读数 + 日期 + 是否过期）
2. **利率环境**（10Y 现值与变动、β_rate、本轮是否改锚——没改也要写）
3. 形态 + 估值范式 + **反方证据**
4. 五档位置 + 仓位分桶（底仓/波段）
5. 结论 + 通道 + 股数/限价
6. 硬约束 pass/fail 表
7. 报告链接 + 「成交后把券商持股数与成本价告诉我」
