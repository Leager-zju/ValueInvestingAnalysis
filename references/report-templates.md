# 四种输出的固定版式

复制结构、替换内容即可。所有模板都以"结论先行"开头，不允许先铺陈数据再给结论。

---

## 落盘版式：一律用 assets/report-template.html

聊天回复用下方 Markdown 骨架；**写入磁盘的报告必须是 HTML**，套用 `assets/report-template.html` 的版式。

做法：读取该文件 → 复制到 `new-report` 返回的槽位路径（`<代码>-open.html` / `<code>-close.html` / `<代码>-deep.html`）→ 只替换文字与数字，不改 `<style>` 与 class 结构。

报告顶部有一条 sticky 导航（`← 报告索引`＋三个槽位互跳），由模板自动注入，**不要删除也不要手写**：它靠文件名 `<代码>-<槽位>.html` 与同目录的 `index.html` 相对路径工作。

**文件名不带日期，永远覆盖写**。每标的只保留 3 个文件，同一天跑两次也只有一个 `-close.html`（后写覆盖先写）。报告里的「生成时间」写在页脚，用它区分版本，不要用文件名区分。

版式已内置的设计元素，不要自己另造一套：

| 元素 | class | 用法 |
|---|---|---|
| 深色页头 + 结论条 + 四格指标 | `.masthead` `.verdict` `.kpis` | 名称、代码、质地与估值徽章、结论、现价/成本/盈亏/可用资金 |
| 白卡片区块（编号 + 标题 + 权重） | `section.card` `.sec-head` `.kicker` `.wt` | 每个分析维度一张卡 |
| 质地评分 | `.score` + `.bar` | 大号分数 + 进度条，一眼看出低分项 |
| **估值五档刻度条** | `.zone` `.zone-bar` `.zone-track` `.z1~.z5` `.marker` | 五段配色 + 现价游标，替代纯文字描述 |
| **上行期权卡** | `.opt-item` `.opt-sum` | 每条期权的概率/窗口/贡献，合计与上限提示 |
| 状态徽章 | `.badge` + `.b-buy/.b-fair/.b-rich/.b-over/.b-up/.b-dn` | 估值区、量价状态、事件方向 |
| 约束核对 | `.pass` `.fail` `tr.rowfail` | 尾盘决策逐条 pass/fail |
| 纪律引用块 | `.discipline` | 尾盘决策末尾固定引用 |
| 提示块 | `.note` `.note.warn` `.note.danger` | 关键解释、未证实项、风险 |

配色语义（写死，不得随意改）：

- **涨红跌绿**：`.up` `#d92020` / `.dn` `#0f8a5f`，与 A 股习惯一致
- **估值五档分级**：深度低估 深蓝 `#0b3fa8`、低估 蓝 `#1a56db`、合理 灰 `#475569`、偏贵 琥珀 `#b45309`、透支 深红 `#b91c1c`
- 数字统一 `class="num"`（等宽 + tabular-nums），保证表格数字对齐

估值刻度条算法（写在模板注释里，照算即可）：

```
left%  = (价位 − axisMin) / (axisMax − axisMin) × 100
width% = (区间上界 − 区间下界) / (axisMax − axisMin) × 100
五段：axisMin–deep / deep–core / core–fair_high / fair_high–透支 / 透支–axisMax
五段 width 之和必须 = 100%，否则会露白
axisMin 建议取 deep_value×0.9，axisMax 取 透支线×1.05
```

区块裁剪：深度报表保留全部；早盘预案删「期权明细」「资金与情绪」，把「结论与操作」换成情景预案表（但必须保留建仓通道）；尾盘决策精简「企业质地」为一行摘要，保留「建仓路径」「约束核对」与纪律块。

## 深度报表额外要求：锚版本与下游影响

深度复核会重算基础价值与四锚，因此除常规区块外，还必须有两行：

```
锚版本：<YYYY-MM-DD HH:MM>（本次复核已更新 / 未变动）
下游影响：今日 14:37 的收盘报告基于旧锚（10-30 10:49），其中「合理区、持有不加」的判断在
          fair_high 由 39.15 调整为 36.80 后仍然成立；建仓窗口由 ≤34.5 收窄到 ≤32.4。
```

- 第一行让用户一眼看出这份报告用的是哪一版锚；
- 第二行只在本日已有其他报告**且锚确实变了**时才写，说明哪些判断失效；
- 锚未变动时，第一行写「未变动」即可，第二行可省。

## 落地后必跑自检

写完 HTML 必须执行一次：

```bash
python <skill>/scripts/portfolio.py lint-report --code <代码> --session <deep|morning|afternoon>
```

它检查五件事，其中第 1 条最要命：

| 检查 | 后果 |
|---|---|
| `<style>` 与 `:root{` 之间有杂文本 | **整条 `:root` 被 CSS 解析器丢弃 → 所有变量失效**：页头白字白底、涨跌颜色消失 |
| `style` 标签未成对 | 后续内容被当成 CSS 吞掉 |
| HTML 注释未闭合 | 页面结构错乱 |
| `var(--x)` 有未定义的变量 | 对应样式静默失效 |
| 缺少驱动因子 / 公司性质 / 结论区块 | SKILL 要求必填 |

`errors > 0` 时不得交付。

> **模板注释的硬约束**：注释里不得出现任何标签字面量。以 `<style>` 为切分点拼接页面时，若注释中含标签，切点会落在注释中间，`<style>` 后面接上注释残文，`:root` 一起被吞，页头变成白字白底。**这类失效浏览器不报错，所以自检不能省**。

## 收尾格式：每个块尾推一张报告卡片

每只标的独立成块，**块尾用 `present_files` 推该标的自己的那份报告**——不写链接、不写纯文本路径。

> 1. <标的A>（<代码A>）：持有不动，合理区 41% 位
> 　→ `present_files(["…/reports/<代码A>-close.html"])` 生成卡片
>
> 2. <标的B>（<代码B>）：建底仓 100 股 @≤<价格>，明日开盘
> 　→ `present_files(["…/reports/<代码B>-close.html"])` 生成卡片

**为什么不用 Markdown 链接**：`[文字](file:///...)` 在客户端里不会被渲染，只会显示成一串方括号——实测 `file://` 被安全策略拦掉，只有 http(s) 能点。

**整篇结尾只推一次索引**：点开任一报告卡片后，顶部就有「← 报告索引」和三槽位互跳，索引一步可达。逐只重复推索引只会增加卡片数量。

规则：
- 一次 `present_files` 只放**一个文件**——放多个会一次性打开全部，正是要避免的；
- 标的超过 3 个时，改为只在最后一个块尾推一次 `index.html`；
- 卡片文案进不了自定义，报告本身的 `<title>` 就是卡片标题，所以报告标题要写成「名称 · 槽位」便于辨认；
- 桌面/文件管理器里的 `index.html` 快捷方式是对话之外的第三条路，适合不经过任何 AI 客户端、直接看报告的场景。
