# 首次使用：环境自检与投资者画像

首次调用本技能时，按顺序做三件事：**检查 Python → 确认数据源 → 问答式画像**。全部完成后才进入建档。

---

## 一、环境自检（Python）

### 检查

```bash
python --version      # Windows 优先
python3 --version     # macOS / Linux 优先
```

任一返回 **3.9 及以上**即通过。脚本只依赖标准库，**不需要 pip 安装任何包**。

### 未检测到 Python 时

**不要静默失败，也不要用别的语言重写脚本绕过。** 用 `AskUserQuestion` 询问，选项：

| 选项 | 说明 |
|---|---|
| 安装 Python（推荐） | 我执行安装命令，需要网络与管理员权限 |
| 我自己装 | 给出官方下载地址，装完告诉我 |
| 暂时跳过 | 只能提供文档级建议，无法运行持仓脚本与生成报表 |

### 同意安装后

| 系统 | 命令 |
|---|---|
| Windows | `winget install -e --id Python.Python.3.12`（无 winget 则引导到 python.org/downloads 下载 pkg） |
| macOS | `brew install python@3.12`（无 brew 则引导到 python.org 下载 universal2 installer） |
| Linux (Debian/Ubuntu) | `sudo apt-get update && sudo apt-get install -y python3` |
| Linux (Fedora/RHEL) | `sudo dnf install -y python3` |

执行前必须说明：**这会修改系统环境、需要管理员权限与网络、安装后需重开终端才生效。**

装完验证 `python --version` 或 `python3 --version`，再跑一次 `portfolio.py path` 确认脚本可用。

> 若用户拒绝安装：记录「环境未就绪」，本轮只做文档级分析（说明取数与检查逻辑），不声称已经算过任何数字。

## 二、投资者画像（分两层）

画像不是一整套参数，而是**两层**：

| 层 | 属于谁 | 何时确认 | 包含 |
|---|---|---|---|
| **全局画像** | 人（跨标的不变） | 首次使用，只问一次 | 踏空厌恶、可承受浮亏 |
| **标的画像** | 这只票的执行策略 | **每只标的首次分析时** | 建仓风格、建仓窗口、波段仓 |

分两层的原因很实际：**你对亏损的忍受度是稳定的，但"这只票该怎么做"是因股而异的**——周期股适合越跌越买，稳健成长股适合等回归，重仓标的可能干脆不划波段仓。用一套参数套所有标的，必然有一半是错的。

### 设计原则

1. **问行为，不问参数。** 用户不知道 `regret_aversion` 是什么，但清楚自己上次在什么价位下的手。
2. **4 题、每题 3 选项、2 分钟。** 超过 5 题会被敷衍，答案反而更不准。
3. **冲突取保守档。** 见下文映射规则。
4. **不让用户敲命令。** 由 agent 汇总答案后调用 `set-prefs` 写入。

### 问卷

### 2.1 全局画像（属于人，只问一次）

**Q1｜追价意愿**
> 你研究很久、但一直觉得"还不够便宜"的一只股票，如果它始终不回调，你会：

| 选项 | 倾向 |
|---|---|
| A 一直等，等到我算出来的深度折价 | `low` |
| B 先在合理区买一点底仓，跌了再补 | `mid` |
| C 先把能承受的仓位建够，再慢慢调整 | `high` |

**Q2｜后悔方向**
> 过去一年，更让你难受的是：

| 选项 | 倾向 |
|---|---|
| A 买早了被套，或者下手太急 | `low` |
| B 卖早了、或者压根没敢买，看着它涨 | `high` |
| C 差不多，两种情况都有 | `mid` |

**Q3｜资金期限**
> 这笔钱大概多久用不上？

| 选项 | 承受区间 |
|---|---|
| A 3 年以上 | 0.35 |
| B 1–3 年 | 0.25 |
| C 1 年内可能要用 | 0.15（并提示：本框架假设 3 年以上持有期，短期资金不适用） |

**Q4｜浮亏容忍**
> 单只股票浮亏多少，你还能按计划执行、不至于睡不着？

| 选项 | 承受区间 |
|---|---|
| A 30% 以上 | 0.35 |
| B 15%–30% | 0.25 |
| C 15% 以内 | 0.15 |

### 2.2 标的画像（属于这只票，首次分析该标的时问）

下面三题**每只标的各问一次**。同一只票在换仓、加减仓后可以重设。

#### 先讲清四种风格，再问

**问之前必须先解释**，否则用户只能凭名字猜。以下是可直接照搬的口径。

---

**A｜左侧摊薄型 — "越跌越买"**

> 你觉得跌下来就是更便宜，所以一路买下去，用更低的价格把平均成本拉低。

- 例子：10 元买 1000 股 → 跌到 9 元再买 → 跌到 8 元再买。成本一路降，但**仓位也一路加上去**。
- 代价：可能一路买到半山腰甚至更深，而底是事后才知道的。
- 适合：现金流稳定、看得懂这家公司底在哪、且能承受仓位变重的人。

---

**B｜纪律波段型 — "买贵了用波段磨回来"**

> 你接受买在半山腰，但不无限加仓。买高了就等反弹卖一部分（不超过持仓的 1/3），跌回来再买回，用差价把成本磨下来。

- 例子：24.4 买 300 股 → 反弹到 26.8 卖出这 300 股 → 跌回 25.4 再买回。**股数没变，成本降了。**
- 关键纪律：只能"先卖后买"；卖出那一刻就要写下买回价（≤卖价×95%）；买不回就认，不追高。
- 代价：卖出后不回落，就变成踏空——所以波段仓要小。

---

**C｜右侧确认型 — "不猜底，等它自己站起来"**

> 你不买下跌中的股票，等它止跌回升、走出一个确认信号再买。

- 例子：跌到 18 元不买，等它从 18 涨回 20 元并且站稳，再买。**买得贵一点，但躲开了继续下跌。**
- 要坦白的一点：**本框架不提供右侧追入信号**——它靠"价格 vs 内在价值"的偏离下单，不靠趋势确认。选这个风格，本技能只服务你的价值仓（底仓线以下才买），趋势仓要另开一本账。
- 适合：吃过"越跌越买"的亏、宁可买贵也不愿被套的人。

---

**D｜混合 / 基本面优先 — "先看基本面，再决定动作"**

> 你不预设"跌了就买"还是"等反弹"，每次加仓前先确认一件事：基本面有没有变？变了就按规则减，没变就按价格执行。

- 例子：跌到买入区间，先看最近一期财报和驱动因子——没恶化就按计划买，恶化了就停手并复核。
- 默认窗口最小（合理区下 1/3），因为它假设"没有明确风格，就保守一点"。
- 适合：还没想清楚自己偏左还是偏右、或者认为不同情况该不同处理的人。

---

**一句话对照**

| 风格 | 跌了 20% 你会 | 最大的风险 |
|---|---|---|
| A 左侧摊薄 | 继续买，拉低成本 | 仓位越加越重，底还很远 |
| B 纪律波段 | 不动，等反弹卖一部分再买回 | 卖飞了变成踏空 |
| C 右侧确认 | 不买，等它止跌回升 | 买得贵，且框架不提供这类信号 |
| D 混合 | 先看基本面有没有变 | 可能错过窗口，动作偏慢 |

---

**选项文案要求（给 AI）**：`AskUserQuestion` 的每个选项 `description` 里，必须写清"**这种情况下你能做什么、不能做什么**"，不要只写风格名称。例如：

- ❌ `左侧摊薄型`
- ✅ `越跌越买，能压低均价，但仓位会一路加重`

**Q5｜建仓风格**
> 一只票从你设的目标价继续跌 20%，你更可能：

| 选项 | 倾向 |
|---|---|
| A 分批继续买，把均价摊下来就好受 | `left` 左侧摊薄型 |
| B 先不动，等反弹到某个位置卖一部分、再在低位买回 | `swing` 纪律波段型 |
| C 等它止跌回升、突破某个位置再买 | `right` 右侧确认型 |
| D 先看基本面有没有变，再决定 | `mixed` 混合/基本面优先 |

**Q6｜买贵了怎么办**
> 买完就跌 15%，而基本面没有任何变化，你的第一反应是：

| 选项 | 倾向 |
|---|---|
| A 继续加，拉低均价 | `left` |
| B 不动，等反弹做一次高抛低吸 | `swing` |
| C 认错减仓，等右侧再进 | `right` |
| D 什么都不做，按原计划执行 | `mixed` |

**Q7｜波段仓划分（仅当风格为 swing / left 时问）**

**先算再问**：跑 `plan-swing --code C --price P`，它会按可用资金算出"最多可买 N 股"，并给出建议比例与理由。然后把建议摆给用户：

> 按现价 <P> 与可用资金 <金额>，这只票最多可买 **N 股**。
> 我建议把其中 **X%**（≈ Y 股）划为波段仓，理由：<形态基准 / 质地调整 / 踏空厌恶调整>。
> 你想划多少？A 采纳建议 · B 不划波段 · C 划三分之一 · D 其他比例

| 选项 | 结果 |
|---|---|
| 采纳建议 | 建议比例 × N，向下取整到每手 |
| 不划波段 | 0 股，全部当底仓 |
| 三分之一 | N × 33%，向下取整到每手 |
| 其他 | 用户给的比例，同样取整到每手 |

**建议比例怎么算**（`suggest_swing_ratio`，结果封顶 35%，**但这只是软建议**）：

| 因素 | 调整 |
|---|---|
| 形态基准 | 周期型 30% / 缓慢增长 25% / 快速增长 20% / 稳健增长 15% / 困境反转 10% / 隐蔽资产 10% |
| 质地 ≥9 | ×0.8 —— 好公司少折腾，卖飞了很难买回 |
| 质地 8 | ×1.0 |
| 质地 7 | ×0.8 |
| 质地 <7 | **直接建议 0**：不确定性大，做波段容易变成踏空 |
| 踏空厌恶 high / mid / low | ×0.8 / ×1.0 / ×1.2 |
| 上限 | **没有硬上限**（分桶只问底仓，波段仓 = 总持仓 − 底仓自动派生）。35% 只是建议值的软封顶，不是规则 |

> **建议只是建议。** 用户不采纳是常态，说明一次理由即可，不要反复劝。参数最终以用户的决定为准——这是他的钱。

> 说明：底仓**永不参与波段**，只有基本面恶化或估值透支才动；波段仓只做"先卖后买"，卖出时必须同时给出买回价。

### 映射规则

**全局（Q1–Q4）**

```
regret_aversion    = Q1 与 Q2 的多数结论
                     · 两者一致 → 取该档
                     · 两者冲突 → 取更保守的一档（low < mid < high）
drawdown_tolerance = min(Q3, Q4)          # 取更保守的
```

**标的（Q5–Q7）**

```
entry_style      = Q5 与 Q6 的多数结论
                   · 两者一致 → 取该风格
                   · 两者冲突 → 取 mixed（行为本身不稳定，先按基本面优先）
entry_zone_ratio = 跟随 entry_style 的默认值（见下表），可单独覆盖
swing_shares     = Q7 的选择 × 该标的持股数（向下取整到每手）
```

**为什么 regret 冲突时取保守档**：偏好一旦偏激进，会系统性地把仓位推高，错误是单向放大的；保守档的代价只是可能少赚一点。**不对称的错误，就选代价小的那一侧。**

**为什么风格冲突时取 mixed**：Q5 与 Q6 问的是同一种处境下的两种反应，答案不一致说明行为本身不稳定。这时不要假装有明确风格，退回「每次先看基本面」最安全。

### 四种建仓风格及其硬约束

| 风格 | 窗口 | 允许的动作 | 硬约束 |
|---|---|---|---|
| `left` 左侧摊薄型 | 100%（整个合理区） | 越跌越买、分批承接 | 累计不超过该标的 `budget`；每轮间距 ≥5%；最多 3 轮；跌破深度低估线后停止摊薄，改看 A 类信号 |
| `swing` 纪律波段型 | 50%（合理区下半段） | 建底仓 + 先卖后买的波段修复 | 必须「先高后低」、买回 ≤ 卖价×0.95、单次 ≤ 持仓 1/3、买不回不追高（见 decision-rules 第 7 节） |
| `right` 右侧确认型 | **0%** | 只在底仓线及以下建仓 | **本框架不提供右侧追入**；若确要做趋势仓，须单独记账、≤总资金 10%、配移动止损，不计入价值仓 |
| `mixed` 混合/基本面优先 | 33%（合理区下三分之一） | 建底仓，每次先复核基本面 | 基本面未变才执行；不预设摊薄或波段 |

关于 `right` 要坦白：**价值框架天生是左侧的** —— 它靠"价格 vs 内在价值"的偏离下单，不靠趋势确认。硬套右侧会在高估值区间买入，与整套逻辑冲突。所以选 `right` 的用户，本技能只服务其价值仓部分，趋势仓另算。

### 写入：两条命令，两层互不干扰

**全局（只跑一次）**

```bash
python <skill>/scripts/portfolio.py set-prefs \
  --regret-aversion high --drawdown-tolerance 0.25 \
  --profile-note "全局 Q1=B Q2=B Q3=A Q4=B → high / 0.25"
```

**标的（每只票各跑一次）**

```bash
python <skill>/scripts/portfolio.py set-profile --code 600096 \
  --entry-style swing --swing-shares 300 \
  --note "周期股，接受买贵，用先卖后买的波段修复；波段仓约 27%"
```

`--profile-note` / `--note` 必须记下原始答案，方便日后复核与换机迁移时重建画像。

### 2.3 两层的优先级

```
标的画像 > 全局画像 > 风格默认值
```

- `regret_aversion` / `drawdown_tolerance` 只认全局——它们是人的属性，不该某只票一个样；
- `entry_style` / `entry_zone_ratio` 优先取标的级，标的没设才回退全局；
- `swing_shares` 天然是标的级（每只票持股数不同）。

`calc` 会返回 `trading_profile.source`，标明每个参数当前来自 `holding` 还是 `global`，一眼能看出有没有漏设。

**建议但不强制**：定标的画像时可参考公司形态——周期型常配 `left`/`swing`（越跌越买或波段降本），稳健增长型常配 `mixed`（等回归），快速增长型若波动大也可配 `swing`。但形态只作提示，最终以你对这只票的判断为准。

### 三条硬性提醒

1. **Q3 选 C（1 年内要用）时不要继续建档**：本框架的前提是 3 年以上持有期，短期资金会被迫在错误的时间卖出。应明确告知不适用，让用户决定是否换一笔长期资金。
2. **画像可随时重做**，但**不要在浮亏扩大时重做**——那时给出的答案代表情绪，不代表偏好。要重做，等账户回到成本附近或空仓时再问。
3. **`right` 与 `left` 不能混用**：前者要求价格确认后追入，后者要求越跌越买，两种操作在同一标的上会互相抵消。选定一种并在复核时保持一致。
4. **不要把画像当成收益承诺**。高承受度不等于该上杠杆，参数只影响"何时建仓、建多少"，不影响"是否该买"。

## 二·五、"买在最低点上方 1%" 是一个会害人的标准

很多人对理想操作的想象是「买在最低点上方 1%、卖在最高点下方 1%」。这个标准无法执行，而且**与"厌恶踏空"直接冲突**：

- 判断"最低点"需要事后信息，事前只能猜；追求 1% 精度 = 必须等确认，而确认时价格已经起来了；
- 越追求精确的低点，空仓时间越长，踏空的概率越高——**恰恰是更厌恶踏空的人最不该采用的标准**。

框架给出的替代方案不是"更准地预测底部"，而是**不预测底部**：

| 做法 | 说明 |
|---|---|
| 价格阶梯 | 按 low / core / deep 分档挂单，能接到哪档是哪档 |
| 窗口内分批 | 价格落在窗口内就可以按档买，不落在窗口内就不买（**不看时间**，只看价格） |
| 仓位分层 | 底仓 1/3、加仓 1/3、预留 1/3 给黑天鹅 |

代价是拿不到"最低点"，收益是不用靠猜。**接受"买在偏低区间"而不是"买在最低点"，是这套框架能跑起来的前提。**

反过来，卖点也一样：不追求最高点，而是等估值进入透支区再减——`overvalued_above_price` 就是"不猜顶"的产物。

## 三、三个参数分别影响什么

| 参数 | 默认 | 影响 |
|---|---|---|
| `regret_aversion` | `mid` | 空仓时的建仓门槛：`low` 只等深度折价；`mid` 低估区建底仓；`high` 允许在合理区内用「时间换价格」分批建底仓 |
| `drawdown_tolerance` | `0.25` | 浮亏超过该阈值时，`calc` 返回 `emotion_guard`：提示只按既定通道执行，不临时加仓或减仓 |
| `entry_zone_ratio` | `0.33` | 「时间换价格」窗口占合理区的比例：`0` = 只在底仓线建、`0.33` = 合理区下 1/3、`1` = 整个合理区。**既厌恶踏空又厌恶买在半山腰的人，把它调到 0.2–0.33 之间** |

`emotion_guard` 的作用是**不阻止交易，只提醒判断可能被情绪污染**。它出现的时刻，往往正是最想"做点什么"的时刻。
