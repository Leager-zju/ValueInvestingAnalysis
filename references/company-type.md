# 公司性质的判定与使用

## 0. 先摆正位置：分类是「找因子的向导」，不是结论

一句话：**分类是一个标签，因子才是实体。**

任何一家公司的股价都受若干具体因子影响——产品价格、销量、成本、订单、装机、批价、库存、政策。这些因子是真实存在的、可观测的、可验证的；而"它是成长股还是周期股"只是我们为了方便而贴的一个标签。

由此有三个推论，决定了本文件的用法：

1. **分类对了但因子漏了，结论一定错；分类错了但因子挖全了，结论通常仍然对。** 因为估值最终要落到"因子 → 盈利 → 价格"这条链上，标签本身不进入计算。
2. **同一分类下的两家公司，因子可以完全不同。** 两只都是稳健增长型：一只靠每年提价 5%（看批价与渠道库存），另一只靠装机量翻倍（看招标与排产）。用同一套因子清单去套，第二只必然漏看。
3. **所以流程是**：分类 → 提示该看哪一类因子（防漏）→ **挖掘个股特有的因子**（真功夫）→ 用因子推盈利 → 再谈估值与价格。分类只在前两步出现，之后它就退场了。

**分类真正有用的三个地方**：

| 用途 | 说明 |
|---|---|
| 提供因子池的先验 | 防止"只看财报不看行业"，尤其是第一次研究某行业时 |
| 提供默认的估值尺子 | 周期股默认 CAPE+PB、快速增长默认 PEG，省去每次重想 |
| 提供失效信号的默认清单 | 每类公司"通常怎么死"是有规律的 |

**分类不该用的地方**：不能因为"它是周期股"就不去看它的个股特有因子；不能因为"它是稳健增长型"就默认它的增长可持续。**标签是起点，不是终点。**

### 形态 → 该形态最该盯的因子类别

这张表是分类与因子之间的唯一接口，判定完形态后据此起手，然后立刻转到个股特有因子。

| 形态 | 起手因子（防漏用） | 最容易漏掉的 |
|---|---|---|
| `slow_grower` 缓慢增长型 | 股息率与分红的 FCF 覆盖、份额变化、资本开支纪律 | 分红是否靠举债维持 |
| `stalwart` 稳健增长型 | 提价幅度与批价、渠道库存、份额、ROE 的持续性 | 增长是否已到天花板（涨多了要换股） |
| `fast_grower` 快速增长型 | 订单/在手合同、装机/开店/单店模型、capex 到收入的转化 | 增速里的并表与低基数成分 |
| `cyclical` 周期型 | 产品价差、**库存**、在建产能/开工率、成本曲线位置 | 库存（林奇强调的见顶信号） |
| `turnaround` 困境反转型 | 现金/短债与到期结构、现金流转正时点、重组进度 | 会不会二次恶化 |
| `asset_play` 隐蔽资产型 | 资产可变现性、负债侵蚀、**催化剂是否真实存在** | 没有催化剂的折价可以持续十年 |

**因子清单永远优先于分类**：当两者冲突时——比如一家被判为周期型，但你发现它的长协占比已达 70%、价格波动被锁定——**以因子为准**，并据此申请改判形态（见第 4 节闸门三）。

---

参考彼得·林奇《彼得林奇的成功投资》的六分法：**缓慢增长型 / 稳健增长型 / 快速增长型 / 周期型 / 困境反转型 / 隐蔽资产型**。

但**不照搬**，原因有三：

1. **增速门槛带有时代印记**。林奇写书时美国处在两位数通胀环境，"稳健增长 = 10–12%"、"快速增长 = 20–25%" 是那个年代的刻度。今天要按当下的名义增长环境重新校准，否则会把这十年里正常的 15% 增长误判成"快速增长"。
2. **六类里没有"金融"**。不是遗漏，是因为当年用 PB 就能处理银行保险。但金融股的资产质量、拨备、息差是一套独立的分析语言，必须从"形态"里拆出来，作为**估值范式**而不是一类公司。
3. **林奇本人也说分类是艺术**。他在书里承认会看错、会改判。既然分类本身有主观性，就必须用**可验证的量化门槛 + 反向证据**去约束，而不是靠印象。

所以本框架分两个维度，并加四道防偏差的闸门。

## 1. 两个维度，不要混用

| 维度 | 回答什么 | 取值 |
|---|---|---|
| **形态** `primary` | 增长从哪来、能持续多久 | 六类之一，**只能一个** |
| **估值范式** `valuation_model` | 用哪把尺子量它 | PE 分位 / PEG / CAPE+PB / 股息率锚 / PB–ROE / RNAV / 正常化盈利 |
| **属性** `tags` | 行业与政策特征，影响关注点 | 红利、金融、资源、平台、政策敏感…（0–2 个） |

一家银行的形态可能是"稳健增长型"，但估值范式是 `pb_roe`；一只高分红的水泥股形态是"周期型"，属性带"红利"，估值范式是 `cape_pb` 而不是股息率锚。**形态与范式分离，才不会出现"因为是银行所以只能用 PB"这种偷懒。**

## 2. 判定顺序（第一个命中即为 primary）

先看营收与利润的**三年 CAGR，取两者中较低的那个**——用低的那个是为了防止低基数或一次性并表把增速美化。

| 顺序 | 条件 | 判定 |
|---|---|---|
| 1 | 近 2 年至少 1 年净利润为负，且正在修复（非结构性衰退） | `turnaround` 困境反转型 |
| 2 | 近 10 年出现年度亏损 **或** 净利峰谷比 >3 倍，且毛利率变化与大宗价格同向 | `cyclical` 周期型 |
| 3 | 市值 < 重估资产净值（RNAV）的 0.8 倍，且**有明确的价值释放催化剂** | `asset_play` 隐蔽资产型 |
| 4 | 营收与利润 CAGR 均 ≥20%（或收入未起但订单/装机/在手合同可验证） | `fast_grower` 快速增长型 |
| 5 | CAGR 在 5%–20% 之间，ROE 稳定 ≥12% | `stalwart` 稳健增长型 |
| 6 | CAGR < 5%，行业成熟，增长主要靠份额微调与提价 | `slow_grower` 缓慢增长型 |

**顺序不能颠倒**：先排除"亏损/修复"与"周期波动"，因为这两类会让所有增速指标失真；再判"隐蔽资产"，因为它常常伪装成低增长的烂公司；最后才按增速分档。

**股息不是形态**。高股息是 `slow_grower` 与 `stalwart` 常见的**结果**，不是原因。所以"红利股"作为 `tags` 存在，不作为 primary。判定时若股息率 ≥4% 且分红率 ≥50%，同时挂 `dividend` 标签。

## 3. 六类详解

### `slow_grower` 缓慢增长型

- **判据**：CAGR < 5%，行业成熟（需求见顶或存量竞争），增长靠提价与份额。
- **估值范式**：`pe_band` 或 `dividend_yield`。
- **重点看**：股息率与分红可持续性（FCF 覆盖 ≥1.2 倍）、份额是否在流失、资本开支是否在无谓扩张。
- **林奇提醒**：这类公司最大的风险是"用成长股的价钱买它"。他买这类只为拿股息，且一旦基本面转差（分红削减）立刻卖。
- **陷阱**：把"低增长但高分红"当成安全，忽略分红本身来自举债。

### `stalwart` 稳健增长型

- **判据**：CAGR 5%–20%，ROE 稳定 ≥12%，通常是行业龙头、大市值。
- **估值范式**：`pe_band`（历史分位）。
- **重点看**：ROE 的持续性、毛利率与提价能力、份额与渠道库存、估值中枢是否在漂移。
- **林奇提醒**：这类是他组合的主力，但**涨到 30%–50% 就该考虑换股**——因为它们的成长有天花板，估值扩张不可持续。这条对今天的启示是：**不要把稳健增长当成可以无限持有的成长股**。
- **陷阱**：把周期股在景气高点误判为 stalwart（盈利平稳几年，看起来像稳健增长）。

### `fast_grower` 快速增长型

- **判据**：CAGR 均 ≥20%，且增长可持续（不是靠并表、补贴、低价换量）。
- **估值范式**：`peg`（P/E ≤ 增长率，PEG ≤1 才算便宜）。
- **重点看**：增速的质量、资本开支到收入的转化周期、一致预期方向、第二曲线是否可计量、可复制性（单店/单产品能否复制到全国/全球）。
- **林奇提醒**：这是十倍股的主要来源，也是最容易亏钱的地方——他要求**弄清增长故事的具体内容**（哪家店、哪个产品、什么时候饱和），而不是"行业空间大"。
- **陷阱**：把一次性高增长（并表、涨价周期）当成可持续；忽略增速的基数效应。

### `cyclical` 周期型

- **判据**：近 10 年出现亏损年或净利峰谷比 >3 倍，毛利率与大宗价格同向。
- **估值范式**：`cape_pb`（10 年平均利润 + PB 分位）。**当期 PE 是陷阱**：盈利高点 PE 最低。
- **重点看**：产能周期位置（在建/现有）、成本曲线位置、价差与库存、产品价格与销量的边际变化。
- **林奇提醒**：周期股的买卖**时机决定一切**，而且"存货积压 + 产能扩张"是见顶信号。他强调要看**库存**，这是最容易被忽略的先行指标。
- **陷阱**：在盈利最好的时候买入（PE 最低、看起来最便宜）；把周期底部的一次性亏损当成困境反转。

### `turnaround` 困境反转型

- **判据**：近 2 年至少 1 年亏损，正在修复；且不是结构性衰退（行业没消失）。
- **估值范式**：`normalized_eps`（用恢复后的正常化盈利）。
- **重点看**：资产负债表能撑多久（现金/短债、到期结构）、正常化盈利的假设是否可验证、现金流转正的时点、债务重组进展。
- **林奇提醒**：他买困境反转的前提是**"公司不会破产"**（有足够的现金或可变卖资产），且失败要快认——"如果它没能反转，就卖掉，不要爱上它"。
- **陷阱**：把"周期底部亏损"当困境反转（前者会随周期自己好，后者需要公司自己改）。

### `asset_play` 隐蔽资产型

- **判据**：市值 < RNAV × 0.8，且**存在明确的价值释放催化剂**（资产出售、分立、举牌、管理层更替、牌照重估、股权变现）。
- **估值范式**：`rnav`（重估净资产 / 分部估值 / 净现金折价）。
- **重点看**：资产是否真的可变现（土地性质、矿权年限、股权是否流通）、负债是否会吞掉资产价值、大股东是否有动机释放价值。
- **林奇提醒**：**没有催化剂的隐蔽资产等于没有**——折价可以持续十年。他明确说要找"管理层准备做点什么"的公司（卖掉、分立、回购）。
- **陷阱**：只看 PB <1 就以为便宜，忽略资产是收不回的应收账款或卖不掉的工业用地。

## 4. 四道防偏差的闸门

分类本身是主观的，所以必须有机制对冲。

### 闸门一：数据先行，人后到

先按第 2 节的门槛算出结论，**再**把结论与证据摆给用户确认。不允许"用户说是成长股，就按成长股算"。

### 闸门二：必须写一条反方证据

每份判定都要填 `counter_evidence`：**一条支持相反分类的证据**。

- 判成 `stalwart`，反方证据可能是"某季度增速掉到 3%，像 slow_grower"；
- 判成 `cyclical`，反方证据可能是"公司主动去周期化，长协占比提升到 70%"。

写不出反方证据，说明判定太随意，退回重判。

### 闸门三：改类型有门槛

只有**结构性事实**能改类型，短期数据波动不改：

- 可以改：增速连续 8 个季度跨越门槛；主业剥离或转型；破产重整完成；资产注入落地。
- 不可以改：单季利润暴雷、股价大跌、券商下调评级、你自己"感觉不一样了"。

改类型必须**同时重算全部锚定价**（估值范式变了，锚必然变），并记录变更日期与原因。

### 闸门四：用户与数据分歧要留痕，不互相覆盖

用户可能知道数据看不到的事（在谈的注入、未披露的诉讼、渠道调研）。所以：

- 用户不同意数据判定时，记录 `user_view` 与理由，**不改写数据结论**；
- 若用户给出的是"数据看不到的事实"，把它写进 `basis` 作为补充证据，重新走门槛；
- 若只是"我觉得"，则保留用户观点但**按数据结论执行**，同时**提高安全边际一档**（因为存在未定价的分歧风险）。

## 5. 确认流程

1. 按第 2 节算出 primary + model + tags + 至少 2 条量化依据 + 1 条反方证据；
2. 用 `AskUserQuestion` 请用户确认（同意 / 改判 / 加标签）；
3. 写入：

```bash
portfolio.py set-type --code C --primary stalwart --model pe_band --tags dividend \
  --basis "营收CAGR 11.3%、利润CAGR 39.9%（低基数），ROE 20.5%，毛利率43%→57%" \
  --counter "2026Q2 归母增速掉到 +6.45%，有滑向 slow_grower 的迹象" --confirmed
```

4. 报告必须展示：形态 + 估值范式 + 判定依据 + 反方证据 + 该形态的 3 项重点。

未确认（`confirmed=false`）时允许出分析，但报告标注「性质未确认（自动判定）」，且估值范式用默认值。

## 6. 最容易犯的三个错

| 错误 | 为什么容易犯 | 纠正 |
|---|---|---|
| 把周期股当稳健增长 | 景气上行几年，盈利平稳、PE 低，看起来像 stalwart | 先查近 10 年有没有亏损年、峰谷比是否 >3 倍 |
| 把稳健增长当快速增长 | 某两年增速 25%，就按 PEG 给估值 | 用三年 CAGR 且取营收与利润中较低者 |
| 看到 PB<1 就当隐蔽资产 | 账面便宜最直观 | 问一句"谁会来释放这个价值"，没有催化剂就不算 |

## 7. 边界案例

- **未盈利生物科技 / 早期科技**：无利润，六类都不完全适用。归入 `fast_grower` 但**必须标注"未盈利成长"**，估值改用管线 NPV / 平台价值——因为这类没有盈利锚，任何倍数都是故事。
  - **仓位不做任何折算或打折。** `budget` 一律取**用户给定值**，脚本与分析**不得**按公司类型自行减半、打折或另设封顶。是否超配只用「已投 ÷ 用户给定 budget」判断。
  - 理由：仓位是**用户的资金安排**，不是公司性质的函数。公司性质只该影响「用什么尺子估值」和「质地打几分」，不该替用户决定投多少钱。把两者绑在一起，会让一个定性的分类去推翻一个定量的资金决策。
- **控股公司 / 多元化集团**：优先考虑 `asset_play`（分部估值），但若各子公司本身在增长，则按主营的形态判，用 SOTP 做交叉验证。
- **转型中的公司**：允许标 `transition`，写明"从 X 转向 Y，以 Y 为准"，并说明切换的验证节点。
