# 关键驱动因子：识别、登记与跟踪

## 0. 因子优先于分类

股价受若干具体因子影响，这一点不因公司被归为哪一类而改变。**公司性质只是找因子时的向导，因子才是判断的实体。**

- **分类错了但因子挖全了**，结论通常仍然成立——因为估值最终落在"因子 → 盈利 → 价格"这条链上；
- **分类对了但因子漏了**，结论一定错——标签不进入计算，因子才进入；
- 因此：**任何一次分析，交付物里因子清单的完整度，比分类是否精确更重要。**

实践中的含义：

1. 拿不准是哪一类时，**先把因子列出来**，因子往往反过来帮你确认分类；
2. 分类变了，因子清单不一定全变——很多因子（价格、成本、订单）跨形态都存在，只是权重不同；
3. 每次财报或行业数据发布后，**先更新因子读数，再谈估值是否要改**。反过来（先改估值再找理由）就是"用标签代替思考"。

价格是结果，不是原因。**如果一家公司的股价由某几个特定数据驱动，那这几个数据的更新时点，比 K 线形态重要得多。**

早盘 9:30 看不到全天走势，但**能知道隔夜有没有新的行业数据发布**。如果昨天出了能繁母猪存栏、今天出了猪价，那今天开盘的定价逻辑就变了——预案必须以这些因子为主轴，而不是以昨天的收盘价为主轴。

## 1. 什么算「关键驱动因子」

满足以下任一条，就必须登记并纳入跟踪：

1. **先行指标**：领先股价 1–12 个月的数据（能繁母猪存栏之于猪价、硅料价格之于光伏、运价指数之于航运）。
2. **成本变量**：直接决定单位毛利且波动大（硫磺之于磷肥、豆粕玉米之于养殖、锂价之于电池）。
3. **政策变量**：一次文件就能改变行业盈利中枢（出口配额、收储、电价、集采）。
4. **供需缺口指标**：库存、开工率、订单、排产。

**不算驱动因子的**：股价自身的涨跌、技术指标、成交量、市场情绪、券商目标价。这些是结果或噪音。

判断标准一句话：**这个数据变了，你会改变对明年的盈利预测吗？** 会，就是驱动因子；不会，就不是。

**但有一类必须例外单列：折现率因子。** 10 年期美债收益率不改变任何一家公司的明年盈利，却改变你愿意为这份盈利付多少倍。按上面这条判据它会被直接筛掉，结果是"所有标的的合理倍数默认是常数"——在利率大幅波动时这会系统性算错（高久期标的被算贵、买点永远不成交）。处理办法是给它单独一个类别 `category: "rate"`：**只准改倍数、不准改盈利**，规则见 §2.6。

## 2. 因子分级

| 级别 | 含义 | 在早盘预案中的角色 |
|---|---|---|
| `core` | 决定盈利中枢，权重最高 | **必须逐日检查是否更新**；触发条件以它为主轴 |
| `secondary` | 影响节奏与幅度 | 检查更新即可，作为辅助条件 |
| `watch` | 长期观察，短期不构成触发 | 月/季频，只在更新日复核 |

每个因子登记时给 `weight`（0–1，同组内相对重要性），并注明**领先/同步/滞后**（`lead`: leading / coincident / lagging）。**滞后指标只能用于确认，不能用于触发。**

## 2.5 政策 / 政治因子：只能压买价，不能抬卖价

宏观政治事件（选举、关税、制裁、法案、监管转向）确实会大幅影响股价。但**把它当普通因子处理会出大问题**——它的特点是"传导链长、难以证伪、特别容易变成事后叙事"。

所以单独设一类 `category: "policy"`，用四条纪律约束。

### 纪律一：必须落到传导链，写不出就是情绪

```json
{"name": "美国关税清单覆盖磷肥",
 "category": "policy", "level": "secondary",
 "freq": "event", "lead": "leading",
 "channel": "关税落地 → 磷肥出口量下降 15% → 营收 -6% → 每股盈利 -1.8",
 "direction": "bearish", "horizon_months": 12,
 "verifiable": "海关月度出口数据同比",
 "source": "USTR 公告", "latest_date": "2026-11-04"}
```

`channel` 必须串到**财务科目**。只写"地缘政治紧张""选举利好新能源"的，一律拒绝登记。

### 纪律二：只影响买价，不影响卖价

这是最重要的一条。

- 政治不确定性提高的是**折现率**，不是**内在价值**。所以它只能让你把 `core_entry` / `deep_value` **往下压**（要求更高的安全边际），
- **绝不能**用它抬高 `fair_high` 或 `overvalued_above`——那是把"讲故事"算进了估值。
- 脚本层面已强制：政策因子的 `level` 不能是 `core`，不能作为核心盈利驱动。

一句话：**政策消息让股票更便宜，不会让公司更值钱。**

### 纪律三：必须有窗口，过期作废

`horizon_months` 必填，上限 36 个月。超过三年的"影响"无法验证，等于不可证伪。

到期未兑现的自动归入 `policy_expired`，不再参与任何判断。这样"三年前的政策影响"不会一直挂在因子表里。

### 纪律四：不许用当天涨跌反推原因

"今天跌了 → 一定是选举" 是典型的事后叙事。政治因子必须在**事件发生时就登记**（含 channel 与 verifiable），
然后等 `verifiable` 里的数据来验证，而不是拿股价验证股价。

### 常见错误对照

| 错误写法 | 问题 | 改法 |
|---|---|---|
| "地缘政治风险上升" | 无传导链、无窗口 | 落到具体条款 + 具体财务科目 |
| "选举利好新能源" | 没说是哪个补贴、哪家公司哪条产品线 | 补贴条款 → 单瓦售价 → 毛利率 |
| "中美关系恶化" | 太笼统，无法验证 | ADR 退市规则 → 港股流动性折价 → 估值倍数下修 |
| level = core | 把政策当核心盈利驱动 | 降为 secondary 或 watch |

### 报告里怎么写

`calc` 的 `drivers.policy_active` 非空时，报告必须单列一块：

> **政策暴露**：<因子名>（方向 bearish / 窗口 12 个月 / 到期 2027-10-30）
> 传导：<channel>
> 对四锚的处理：仅下调 `core_entry` 由 39.15 → 37.60（安全边际 +4%），**不动** `fair_high` 与 `overvalued_above`。
> 验证点：<verifiable> 的下一次发布。

## 2.6 折现率因子：10 年期美债收益率

**这是唯一一个不属于"盈利驱动"、却必须每只票都登记的因子。** 它不进盈利模型，进的是倍数。

### 2.6.1 为什么不能按 §1 的判据把它筛掉

§1 的判据问的是"这个数据变了，会改变明年的盈利预测吗"。10Y 美债答"不会"，所以它不该动 EPS——但它会动**合理倍数**：

- 10Y 上行 50bp，一只现金流主要在 5 年后的成长股，合理 PE 该下修 5%–8%；
- 同一时点，一家当期现金流充沛的周期股几乎不受影响。

**不登记它，等于假设所有公司的估值倍数永远不变。** 这是过去几轮利率大幅波动里最常见的系统性偏差来源：分子算得很细，分母当成常数。

### 2.6.2 传导链（必须按这条写，不许跳步）

```
10Y 美债收益率 ↑
  → 全球无风险利率 ↑、股权风险溢价（ERP）要求 ↑
    → 折现率 ↑ → 远期现金流现值 ↓（久期越长，折价越大）
      → 合理 PE / PEG / PB 中枢 ↓
        → 四个锚（deep / core / fair_high / overvalued）整体下移
```

A 股另有一条并行支线：`10Y ↑ → 美元走强 → 外资风险偏好下降 / 北向流出 → 高估值成长股承压更快`。

两条支线**同向**时信号最强；**背离**时（如美债上行但人民币升值、北向仍净流入）按"弱化"处理，并在报告里写明背离原因，不要只挑对自己结论有利的那条。

### 2.6.3 登记格式

```json
{"name": "10年期美债收益率",
 "category": "rate", "level": "secondary",
 "freq": "daily", "lead": "leading", "beta_rate": -0.09,
 "channel": "10Y 上行 50bp → 合理 PE 27.0→25.8（−4.5%）→ base_* 同比例下修 → core_entry 下移",
 "direction": "bearish", "latest_value": "4.83", "latest_date": "2026-11-05",
 "source": "新华财经/华尔街见闻纽约尾盘口径（见 data-sources.md §2.5）",
 "weight": 0.15,
 "signal": "月度变动 >+25bp → 复核倍数；2Y 上行快于 10Y → 高久期标的再打一档折扣"}
```

| 字段 | 规定 | 理由 |
|---|---|---|
| `category` | `"rate"`（脚本枚举内） | 与 industry / company / policy 分开统计 |
| `level` | `secondary`，**禁止 `core`** | 它不改变盈利中枢，脚本会拒绝 `core` |
| `freq` | `daily`（最低 `weekly`） | 日频市场变量；周末不更新不算过期 |
| `lead` | `leading` | 领先于倍数调整，也领先于股价 |
| `beta_rate` | **必填**，见下表 | 10Y 每上行 100bp，合理估值中枢的变动 %（负数） |
| `channel` | 必填，且必须串到**具体估值参数** | 只写"利率上行压制估值"等于没写 |
| `latest_value` / `latest_date` | 必填 | 口径与时点见 `data-sources.md` §2.5 |

`beta_rate` 缺省值（**能用个股历史校准就优先用校准值**；用缺省值必须在报告里注明"未校准"）：

| 公司形态 | β_rate | 直觉 |
|---|---|---|
| 快速增长 / 未盈利 / 主现金流在 5 年后 | −15% | 久期最长，杀估值最狠 |
| 稳健增长 / 核心资产 | −9% | 标准久期 |
| 缓慢增长 / 红利 / 公用事业 | −6% | 主渠道是股息率与债息的替代效应，不是久期 |
| 困境反转 | −5% | 主渠道是再融资成本 |
| 周期（资源 / 化工 / 航运 / 猪 / 面板） | −2% | 盈利主导，利率是次要变量 |
| 金融（银行 / 保险） | **0（禁用线性修正）** | 息差与资产质量方向相反，线性修正必错 |

### 2.6.4 四条纪律

1. **只能改倍数，不能改盈利**：不得进入 EPS 预测，不得进入期权 `payoff` 的盈利项。期权倍数随 `base_*` 同步修正可以，凭空加盈利不行。
2. **必须记基准**：做任何修正前，先把建锚时的 10Y 水平写进 `valuation.rate_baseline`（含日期）。**没有基准就不许修正**——否则每次都是相对"上一次"修正，锚会在无人察觉中漂移，事后无法复盘。
3. **修正有上限**：单次复核的倍数修正幅度 **≤ ±15%**。超过必须写明理由并请用户确认；一次改超过 15% 的锚，通常已经是在用宏观叙事替代基本面。
4. **不许用利率下行抬高卖价**：修正只作用于 `base_low / base_mid / base_high`，四锚仍按原公式（买入侧打折、卖出侧全额）从修正后的 base 派生。**不得因为"利率要降了"单独上调 `overvalued_above`**——那是把宏观预期当成了公司价值。

### 2.6.5 阈值（报告里直接引用）

| 10Y 区间 | 环境定性 | 对高久期标的的含义 |
|---|---|---|
| < 4.70% | 宽松 | 倍数可上修，成长股弹性最大 |
| 4.70–4.85% | 中性偏松 | 不构成约束，走自主逻辑 |
| 4.85–5.00% | 压制 | 倍数下修 3%–6% |
| 5.00–5.20% | 明显收紧 | 下修 6%–10%，外资流入放缓 |
| > 5.20% | 系统性 | 暂停按"合理区"给买点，只按低估区等 |

曲线结构要看：**2Y 上行快于 10Y**（加息定价）对高估值最不利；**30Y 单独上行**（财政/信用担忧）利好黄金，不利长久期权益。

### 2.6.6 与政策因子的区别（最容易混的一对）

| | 政策因子 `policy` | 利率因子 `rate` |
|---|---|---|
| 可观测性 | 事件、离散 | 连续、每日报价 |
| 方向 | **只能压买价，不能抬卖价** | **可双向**修正 `base_*` |
| 记录要求 | 窗口 `horizon_months` + 验证点 `verifiable` | 基准 `rate_baseline` + `beta_rate` |
| 过期处理 | 超窗自动作废 | 不失效，但未刷新会进 `stale` |
| 常见误用 | 把叙事当政策 | 把利率当盈利因子 |

一句话：**政策让股票更便宜，利率让股票"该值的钱"变多或变少。**

## 3. 行业因子库（建档时从这里挑，再补个股特有因子）

### 生猪养殖（范例：完整因子链）

```
能繁母猪存栏（领先约 10 个月）
  → 仔猪供给与仔猪价（领先约 6 个月）
    → 生猪出栏量（同步）
      → 猪价（同步）→ 养殖利润 → 补栏意愿（反向，领先下一轮）

并行分支：出栏均重、二次育肥、冻品库存（影响短期供给弹性）
成本端：豆粕、玉米、猪粮比（决定盈亏平衡点）
外生冲击：非瘟/腹泻疫情、收储政策、环保限产
```

| 因子 | 级别 | 频率 | 领先性 | 来源 | 信号含义 |
|---|---|---|---|---|---|
| 能繁母猪存栏（万头，环比/同比） | core | 月度 | 领先 10 个月 | 农业农村部月度生猪产品数据、国家统计局 | 环比连降 3 月 → 供给收缩；同比 >+3% → 供给过剩 |
| PSY（每头母猪年提供断奶仔猪数） | core | 季度/年度 | 领先 10 个月 | 上市猪企年报/调研、涌益、钢联 | PSY 提升会**抵消**存栏下降，产能去化被"效率"吃掉 |
| MSY（每头母猪年出栏肥猪数） | core | 季度/年度 | 领先 10 个月 | 同上 | 与 PSY 同看：存栏 × MSY = 未来出栏量 |
| 仔猪价格 | secondary | 周度 | 领先 6 个月 | 涌益咨询、钢联、地方畜牧局 | 仔猪价先于猪价见顶/见底 |
| 生猪均价 / 猪粮比 | core | 日度 | 同步 | 农业农村部、生意社、上市猪企销售简报 | 猪粮比 <5:1 触发收储预期；<6:1 行业亏损 |
| 出栏均重（公斤） | secondary | 周度 | 同步偏领先 | 涌益、钢联 | 均重上升 = 压栏/二次育肥，短期供给后移 |
| 豆粕 / 玉米价格 | secondary | 日度 | 同步 | 大商所期货、生意社 | 决定盈亏平衡点，成本上行压缩利润 |
| 冻品库容率 | watch | 周度 | 滞后 | 涌益、钢联 | 高库存压制反弹高度 |
| 能繁去化政策 / 收储 | watch | 事件 | 事件驱动 | 发改委、农业农村部公告 | 收储只托底不改趋势 |

> **关键提醒**：只盯能繁存栏会漏掉另一半。若 PSY/MSY 同步提升，存栏下降 5% 可能被效率提升抵消，实际出栏量不减。**三个数要一起看，不能只看存栏。**

### 所有标的共用：折现率因子（每只票都登记）

行业因子决定"赚多少"，这一组决定"值多少倍"。**两只同行业的票，这一组可以完全相同**，不必为每只票单独编。

| 因子 | 级别 | 频率 | 领先性 | 来源 | 信号含义 |
|---|---|---|---|---|---|
| 10 年期美债收益率（%） | secondary | 日度 | leading | `data-sources.md` §2.5 | 月变动 >+25bp → 复核倍数；>5.00% → 高久期标的按下修档处理 |
| 2Y–10Y 利差（bp） | watch | 日度 | leading | 同上 | 2Y 上行更快＝加息定价＝对成长更不利；利差陡峭化本身不等于宽松 |
| 美元指数 / 人民币中间价 | watch | 日度 | coincident | 同上 | 与美债同向时信号增强；背离时写明原因，按弱化处理 |

登记时**三条可以只登第一条（10Y）**，另两条写进它的 `signal` 里作为判读条件，避免因子表膨胀。

## 4. 登记与跟踪

### 4.1 建档时（工作流 A）

1. 先确定公司性质（见 `company-type.md`），再从第 3 节因子库挑该行业的核心因子；
2. 补个股特有因子（单一大客户、单一矿区、单一品种占比 >30% 的，必须单列）；
3. 用 `set-drivers` 写入：

```bash
python .../portfolio.py set-drivers --code sz000001 --file drivers.json
```

```json
{
  "industry": "生猪养殖",
  "note": "股价主要由猪价与产能去化预期驱动，与能繁存栏高度相关",
  "drivers": [
    {"name":"能繁母猪存栏","kind":"供给","level":"core","freq":"monthly","lead":"leading","weight":0.35,
     "source":"农业农村部月度生猪产品数据","why":"决定 10 个月后的生猪供给",
     "signal":"环比连降 3 月→收缩；同比>+3%→过剩"},
    {"name":"PSY","kind":"效率","level":"core","freq":"quarterly","lead":"leading","weight":0.2,
     "source":"上市猪企年报/调研、涌益","why":"效率提升会抵消存栏下降",
     "signal":"PSY 同比>+8% → 产能去化被抵消"}
  ]
}
```

4. **报告必须展示因子链**，而不只是列指标：谁领先谁、传导需要多久、当前处在链条哪一环。

### 4.2 早盘（9:30）——因子的作用是"决定今天该看什么"

早盘拿不到连续竞价，但拿得到**隔夜/昨日发布的行业数据**。顺序必须是：

1. **先查因子，再查价格**：读 `calc` 返回的 `drivers`，逐个确认是否到了更新周期（`stale` 列表）。
2. 对 `core` 因子：检索是否有新数据发布（日频直接取，周/月频看是否在近 1–3 天内发布）。
3. **若有因子更新且方向明确** → 今天的预案以该因子为主轴，写清"因子变化 → 对盈利预测的影响 → 对应动作"。
4. **若无因子更新** → 明确写"今日无因子更新，预案以价格位置与既定通道为准"。**不要让价格在真空里代替因子说话。**
5. 因子读数写回 `latest_value` / `latest_date`，避免下次重复检索。
6. **读数变了要判「是不是越过锚复评阈值」**：`calc.reanchor` 会直接告诉你。若不空，今天的预案第一句就是「锚该重评了」，而不是在旧锚里继续找位置——阈值与处理流程见 `decision-rules.md` 6.5。

> 因子的第一用途常被理解成「解释今天的涨跌」，其实是**「决定锚还成不成立」**。价格与锚的关系会在真空区里失效（`core_entry ~ fair_high` 之间没有任何买入通道），唯一能打破僵局的是因子兑现让锚移动。所以因子读数不只是报告素材，它是锚的触发器：读数越界 → 重跑锚 → 买点自随之上移。

### 4.3 尾盘（14:30 / 15:30）

因子是当日信息的来源之一：如果盘中出了行业数据（如午间发布的价格指数），它比量价形态更能解释今天的走势。**因子变化可以推翻量价结论，反之不成立。**

## 5. 数据来源与降级

下表工具名均为**能力占位符**，各平台等价实现见 `platform-adapters.md`；没有同名工具不代表可以跳过取数。

| 通道 | 适用 | 说明 |
|---|---|---|
| 结构化行情工具（`data_*` 或等价） | 股价、财务、板块行情 | 结构化的行情与财报 |
| 结构化检索（`domain_search` 或等价） | 行业数据、商品价格、宏观 | 一句话中文检索意图，返回结构化表 |
| 网页检索（`WebSearch` 或等价） | 部委公告、行业协会、政策文件 | **必须标注来源与发布日期** |
| 上市公司公告 | 销售简报（猪企月度出栏/售价）、经营数据 | 最可靠的一手数据 |

**取不到就写"未取到"并说明对结论的影响**，绝不用记忆值或估算值替代。行业数据尤其容易记错——能繁存栏、猪价的绝对水平每年都在变。

折现率因子（10Y 美债、2Y–10Y 利差、美元指数）走 `WebSearch` / `domain_search` 取，**口径与降级链见 `data-sources.md` §2.5**，不要拿盘中值当收盘值，也不要混用"纽约尾盘"与"收盘"两个口径。

## 6. 常见错误

| 错误 | 后果 | 纠正 |
|---|---|---|
| 用滞后指标做触发 | 猪价涨了才买，往往买在阶段高点 | 区分 leading / coincident / lagging，只用 leading 做触发 |
| 只看单一因子 | 存栏降了但 PSY 涨了，供给没减 | 因子链要成组看，登记时写明相互抵消关系 |
| 因子过期不刷新 | 用三个月前的存栏做今天的决策 | `calc` 会给 `stale` 列表，早盘必须先处理 |
| 把股价/技术指标当因子 | 循环论证 | 股价是结果，不登记为驱动因子 |
| 因子与估值脱节 | 知道猪价跌了，但没算对 EPS 的影响 | 每个 core 因子必须写"变化 → 盈利 → 估值"的传导路径 |
| **把利率当盈利因子** | 用"美债涨了"去改 EPS，或用"利率要降"直接抬卖价 | 利率只改倍数；改盈利必须有营收/成本/订单证据 |
| **登记利率却不记基准** | 每次修正都相对上一次，锚在无人察觉中漂移 | `valuation.rate_baseline` 必填且带日期 |
| **所有公司套同一个 β_rate** | 给银行也套 −9%，方向都可能反 | 按形态取 β；金融（银行/保险）禁用线性修正 |
| **只看 10Y 绝对值不看曲线** | 漏掉"2Y 上行、10Y 下行"这种最伤成长的组合 | 同时读 2Y–10Y 利差，背离时写明原因 |
