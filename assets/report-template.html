本结论可能被推翻的条件

1〔报告期〕报告显示毛利率跌破 〔阈值〕、或经营现金流/净利润 < 〔阈值〕 → 质地降级，重估锚定价
2〔核心因子读数〕持续 〔窗口〕 低于 〔阈值〕 → 渠道利润被压缩，护城河信号转弱
3价格上冲 ≥ __OVERVALUED__ 且一致预期未上修 → 触发估值透支减仓（该线已含期权全额）
下次必查：__EVENT_DATE__ 〔定期报告〕披露后 3 个交易日内，复核基础价值、期权清单（新增/兑现/证伪）与四个锚定价。
